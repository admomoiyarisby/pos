Omoiyari SCM Flow Reference

The shortest useful map of how supply-chain documents move stock and money in the current app.

Core Internal Restocking Flow

1. PRBranch asks Central for ingredients. Status starts Pending. Branch may edit while not processed.
2. ProcessAdmin/AM/Super Admin marks PR Processed. Branch edit is effectively locked.
3. SJ PickingDelivery Note stores ordered/ready/picked quantities. No stock moves yet.
4. In TransitShipping deducts Central stock, writes OUT ledger, creates in-transit rows.
5. Receive + InvoiceBranch receives actual quantity, rejects damaged quantity, then invoice is generated from received quantity only.

Deductions For Ambiguity

PO exists in the schema and server code, but the implemented internal PR path can process a PR directly into an SJ. So the safest reading is: PO is part of the intended hierarchy, but current implementation treats it as an admin-managed optional document path rather than a required gate for branch restocking.

Quarantine is accepted as a rejection disposition, but the current implementation says future enhancement can add a quarantine table. So today it is a recorded exception, not a separate stock bucket with operational controls.
